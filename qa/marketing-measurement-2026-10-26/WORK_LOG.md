# 홍보 기획서 1.1 첫 개발 묶음

기준: 2026-10-26, develop `0a1cd04f0d323ddbdd46e484b880f33a205c6cf4`에서 시작.
요청 문서: Downloads/체스 알까기 홍보와 광고 실행 기획서 (1).md.

## 목표와 보존 조건

- M01: 공개 웹·설치 앱·서버의 현재 상태와 출처 기록. 현재 배포본과 작업 중인 소스를 구분한다.
- M02: 첫 발사·연습 완료·정규 경기·초대·재대결을 실제 승인된 동작에 연결하고, 실패해도 게임은 계속한다.
- M04: 접근 가능한 현재 웹/Android에서 친선전 전체 경로 확인. 연결·발사만 성공해도 3판 완주로 표시하지 않는다.
- 유지: 흑백 기물, 보드, 재질, 물리·밸런스·승리 규칙·턴 진행과 9개 언어. 홍보 수치를 보여 주는 가짜 게임 UI나 효과를 추가하지 않는다.
- 성공 조건: 취소는 첫 발사가 아니고, 연습은 정규 경기 완료가 아니며, 기권과 연결 종료가 정상 승패로 섞이지 않는다. 메뉴로 복귀해도 숨은 경기가 시작된 것으로 세지 않는다.

## 역할

공유 Sol 러너: 분석 코어/검사, SQL 수집·집계/검사, 공개 서비스·연결 Android 기준 상태를 분담.
조정자: 실제 게임 경로 연결, 통합 검수, 문서와 실행 순서 정리.

## 이번에 하지 않은 외부 실행

플랫폼 제출, 광고 집행, 외부 사람에게 연락, 스토어 게시, 커밋·푸시는 포함하지 않는다.
서버 마이그레이션·공개 수집 활성화는 배포 준비와 계정 접근 여부를 확인해 별도로 기록한다.

## 검수 기록의 보완

장치 검수의 두 Sol 러너 명령이 약 11분 뒤 ERROR로 종료되어 최종 응답이 없었다. 저장된 경기 JSON·실제 Android 화면·스크립트를 조정자가 직접 확인하고 남은 검수를 이어갔다. 러너 성공 여부를 게임 통과 여부로 대신하지 않았다.

초기 마우스/터치 검사는 턴 전환만 기록해 발사 승인 증거가 부족했다. 실제 입력을 다시 수행하고 승인 여부와 초기 속도를 관찰했다. 웹/Android 방장을 바꾼 네 번의 발사가 모두 승인됐다. 초기 CDP 선택 실패는 미확인 자동 입력 사례로 남기며, 최종 기기 검사는 ADB 터치 입력을 사용한다. 제품의 조작·물리 코드는 이를 위해 수정하지 않았다.
