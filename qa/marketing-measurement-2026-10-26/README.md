## 구현한 것

- 첫 발사·기초/심화 연습 완료·AI/친구/로컬 경기 시작과 결과·초대·실제 재대결 시작을 기존 게임 흐름에 연결했다.
- 취소를 발사로 세지 않고, 연습을 정규 경기로 세지 않으며, 기권·메뉴 이탈·연결 종료 포기를 구분했다.
- 30분 세션, 동일 기기의 가명 ID 유지, 재전송 중복 제거, 24시간 종료 미확인, KST D1/D7의 관찰 종료 기준을 구현했다.
- 최초 세션 표시가 없는 오래된 재방문 기록은 신규 환경의 분모에서 제외한다. 관찰 기간을 잘라 내보냈을 때의 신규 오집계를 막는다.
- 방 코드를 분석용 해시로 바꾸고 허용된 캠페인 필드만 저장한다. 이메일·닉네임·토큰을 분석 이벤트에 넣지 않는다.
- 서버 수집 RPC, 제한된 접근 권한, 90일 삭제 함수와 조건부 Cron 등록, 관리자용 JSON 집계 도구를 추가했다.
- 빌드 산출물에 `build-info.json`을 추가해 이후 배포본의 커밋·생성 시각·수정 여부를 확인할 수 있게 했다.

새 효과나 안내창은 넣지 않았다. 기존 흑백 기물·보드·조작·턴·물리·승리 규칙을 유지했다. 공개 구버전의 연결 실패만을 근거로 현재 UI를 임의로 바꾸지 않았다.

## 현재 공개 서비스와 Android

[공개 경로 기준 상태](../marketing-readiness-2026-10-26/READINESS.md)에 URL·자산 해시·실제 서버·확인 시각을 기록했다.

- 개발 웹과 기존 GitHub Pages 공개 웹은 서로 다른 자산과 Supabase 프로젝트를 사용한다. 공개본에 정확한 커밋 표기가 없어 소스와 일치한다고 단정할 수 없다.
- 두 서버에 실제 응답이 있었으며, 과거 일시 중지 메일만으로 현재 중지 상태라고 판단하지 않았다.
- 개발 웹 방 생성은 대기 상태에 도달했고, 기존 공개 웹 방 생성에서는 한 차례 P2P 실패가 관찰됐다. 공개 경로의 재현 원인 확정과 재검수가 필요하다.
- 연결 기기는 TB373FU 태블릿이다. 기존 게임이 설치되어 있지 않아 별도 `Chess Marketing QA` 앱으로 개발 코드 검수를 진행했다. Play에서 배포된 앱의 트랙·버전 검수와 구분한다.
- 웹/Android 방장을 바꿔 양쪽 마우스·ADB 터치 발사 4회를 확인했다. 모두 정상 승인됐으며 실제 초기 속도가 기록됐다. [입력 검증 기록](manual-input-results.json)
- 각각 방장으로 연속 3경기를 마쳤고 양쪽 승패가 일치했다. 재대결 총 4회 모두 수락 후 새 판의 0턴으로 진입했다. Android의 3초 백그라운드 복귀, 나가기 취소와 기권 후 상대 결과도 관찰했다. 다른 네트워크 및 경기 중 네트워크 전환은 아직 검증하지 않았다.
- 교차 대전 세부 결과는 [CROSSPLAY.md](../marketing-crossplay-2026-10-26/CROSSPLAY.md)에 기록했다. 자동 경기 완주는 정상 발사 요청과 실제 물리를 사용하며, 신규 이용자의 이해도·재미 검증과 구분한다.

## 배포와 사용자 측 확인

**분석은 기본 꺼짐 상태다.** 후속 사용자 요청으로 `develop` 개발 사이트 배포를 진행한다. 개발 코드 배포만으로 원격 DB 수집을 켜지 않으며, 서버 마이그레이션과 보관·개인정보 안내까지 적용해야 실서비스 수집이 시작된다. 운영 웹과 Play 앱 출시는 별도다. 개발 사이트의 실제 반영 커밋은 `/build-info.json`과 Cloudflare 배포 결과로 확인한다.

| 담당/다음 작업 | 구체적인 일 |
|---|---|
| 개발·운영 계정 담당 | [배포 절차](../../supabase/MARKETING_ANALYTICS.md)에 따라 개발 DB에 개별 SQL 적용, Cron 성공 확인, QA 수집 확인 후 공개 환경에 적용 |
| 스토어 운영자 | 광고할 공개 URL과 실제 Play 트랙/버전을 확인. 개인정보처리방침·데이터 보안 내용을 실제 수집과 맞춤 |
| 사용자와 관찰자 | 처음 하는 사람 5~8명을 대상으로 아래 관찰지 사용. 설명·도움을 준 경우 따로 표시 |
| 다음 개발 묶음 | 미검증 교차 대전 조건을 마친 뒤 M05 CrazyGames Basic의 혼자 체험 빌드와 M06 실제 장면 제작. 서버/공개본 문제를 해결하기 전 친선전 3판을 광고 약속으로 사용하지 않음 |

광고 집행, 플랫폼 제출, 외부 모집 메시지는 이번 개발 배포에 포함하지 않는다. Android 설치 귀속과 설치 후 168시간 완료당 비용은 아직 검증되지 않았으며 집계에서 계산하지 않는다.
