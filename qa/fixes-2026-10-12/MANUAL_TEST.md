# QA 수정 6건 수동 테스트 (2026-10-12)

수정된 `develop` 웹과 Android QA 앱을 함께 테스트합니다. `develop` 푸시만으로 운영 웹이나 Play 스토어 앱이 업데이트되지는 않습니다.

## 준비

- PC 웹: 최신 `develop` 소스와 Node.js 22를 준비하고, 프로젝트 폴더에서 실행합니다. 기존 서버 환경 설정을 사용합니다. 새로 받은 소스라면 `web/.env.example`을 참고해 같은 서버로 설정해야 친선전·랭킹을 확인할 수 있습니다.

```powershell
cd web
npm.cmd ci
npm.cmd run dev
```

- PC에서 `http://localhost:5173`을 엽니다. 포트가 사용 중이면 터미널에 표시된 주소를 사용합니다.
- Android에는 별도로 제공한 `ChessAlkkagi-QA-six-fixes-2026-10-12.apk`를 설치하고 **ChessAlkkagi QA**를 실행합니다. 로컬 배포 파일은 `share/`에 있습니다. 패키지는 `com.chessalkkagi.app.qa`이며 기존 스토어 앱과 별도로 설치됩니다. APK는 Git 저장소에 포함하지 않습니다.
- 친선전은 우선 PC와 Android를 같은 Wi-Fi에 연결해 진행합니다.
- 화면 크기 검사는 PC Chrome/Edge의 `F12` → 기기 도구 모음(`Ctrl+Shift+M`) → 반응형 크기 입력으로 진행합니다. 아래 숫자는 브라우저 화면 영역의 가로×세로 크기입니다. 실제 Android에서도 세로·가로 회전을 확인합니다.

## 1. Android 뒤로가기 — AND-F01

1. 메인 화면에서 **설정**, **랭킹**, **2인 대전의 맵 선택**을 각각 열고 Android 시스템 뒤로가기를 누릅니다.
2. 퍼즐 01을 시작해 뒤로가기를 두 번 누릅니다.
3. 메인 화면에서 뒤로가기를 누른 후 최근 앱 목록에서 다시 엽니다.

**통과:** 열린 창이 닫히며, 퍼즐은 플레이 → 퍼즐 목록 → 메인 순서로 돌아옵니다. 메인에서는 앱이 백그라운드로 내려가고 다시 열 수 있습니다. 대국 중 확인창과 결과 화면은 6번에서 확인합니다.

## 2. 작은 화면의 퍼즐 01 — RQA-01

1. 웹 화면을 **320×568**, **667×375**로 각각 설정하고 퍼즐 01을 시작합니다.
2. 실제 Android에서도 퍼즐 01을 열고 세로 → 가로 → 세로로 회전합니다.

**통과:** 목표 안내와 버튼을 읽고 누를 수 있으며, 목표 기물과 내 기물이 안내창에 가려지지 않습니다. 회전 후에도 같은 상태를 유지합니다.

## 3. 가로 화면의 랭킹 — RQA-03

1. **667×375** 또는 **844×390**에서 랭킹을 엽니다.
2. 끝까지 아래로 스크롤해 **티어와 승급 기준**을 펼쳐 읽고 창을 닫습니다. Android 가로 화면에서도 반복합니다.

**통과:** 하단 안내에 도달하고 펼친 내용까지 읽을 수 있습니다. 선수 목록만 스크롤된다면 **카드 내부의 제목·좌우 여백**에서 다시 스크롤합니다. 카드 바깥 배경을 누르지 않습니다.

## 4. 로그인·회원가입의 키보드 이동 — RQA-02

1. PC 웹에서 **회원가입 / 로그인**을 열고 이메일 로그인 화면의 첫 입력란을 클릭합니다. 이미 로그인했다면 시크릿 창을 이용해도 됩니다.
2. `Tab`을 끝까지 누르고, `Shift+Tab`으로 반대 방향도 확인합니다. 회원가입 화면에서도 반복합니다. 실제 가입은 필요 없습니다.

**통과:** 이메일·비밀번호·회원가입의 닉네임 등 보이는 입력란을 모두 거치고 버튼에도 도달합니다. 첫/마지막 항목에서는 창 안으로 순환하며 배경 메뉴로 빠지지 않습니다.

## 5. 독일어 킹 교환과 프랑스어·일본어 표시 — RQA-04

1. 한국어 상태에서 **2인 대전 → 기본 체스판 → 대전 시작** 경로를 먼저 확인한 뒤, 메인 설정에서 **Deutsch**로 바꿉니다.
2. 같은 경로로 새 대전을 시작합니다. 백 차례에 백 킹을 누르고 **Positionen tauschen**(위치 변경)을 누릅니다. 퍼즐·온라인에서는 이 기능을 사용할 수 없습니다.
3. **360×800**, **320×568**, **667×375**에서 교환 안내를 확인합니다. 빈 바닥을 눌러 취소한 뒤 다시 교환을 켜고 아군 기물을 눌러 교환합니다.
4. **Français**, **日本語**로 각각 바꾸고 **390×844**에서 새 대전을 시작합니다.

**통과:** 독일어 안내가 화면 안에서 줄바꿈되고 끝까지 읽힙니다. 교환 취소와 실제 위치 교환이 됩니다. 프랑스어·일본어에서도 차례 표시와 발사 조작 모드 버튼이 겹치지 않습니다.

## 6. 웹 ↔ Android 친선전 — ONL-F01

1. 양쪽에서 **온라인 랭크 대전 → 초대 코드로 접속 (친선전)**을 엽니다. PC에서 **새 방 만들기**를 누르고, 코드가 준비되기 전에 취소한 뒤 다시 방을 만듭니다. 준비가 빨리 끝난 경우 Android 방장 순서에서도 취소를 시도합니다.
2. 준비된 **12자리 코드**를 Android에서 입력해 참가합니다. 하이픈이 표시된다면 표시된 코드 전체를 복사해도 됩니다.
3. 각자 차례에 직접 한 번씩 발사합니다. 시간이 다 되어 자동 발사되기 전에 조작하고, 움직임이 멈춘 뒤 두 화면의 기물 위치와 다음 차례를 비교합니다.
4. 대국 중 Android 시스템 뒤로가기 → 포기 확인창에서 다시 뒤로가기를 누릅니다. 대국이 계속되는지 확인합니다.
5. PC 쪽에서 대국을 포기합니다. Android의 승리 결과에서 시스템 뒤로가기를 눌러 메인으로 돌아옵니다. 광고가 나오면 닫은 뒤 복귀를 확인합니다.
6. 이번에는 **Android에서 방을 만들고 PC에서 코드를 입력**합니다. Android에서 생성 중 취소·재시도도 해 보고, 연결되면 3~5번을 반복합니다.

**통과:** 준비 중에는 미완성 코드가 노출되지 않고, 취소 후 재시도가 가능합니다. 양방향 연결·직접 발사·차례 전달이 되며 확인창 취소와 결과 화면 복귀가 동작합니다. 느린 환경에서는 코드 준비에 약 15초가 걸릴 수 있습니다. 전체 연결 시간의 상한이 15초라는 뜻은 아닙니다.

## 문제가 생기면

항목 번호, 기기/OS·브라우저 버전, 화면 크기·방향, 언어, 재현 순서, 기대 결과와 실제 결과, 스크린샷 또는 짧은 영상을 남겨 주세요. 친선전은 어느 쪽이 방장이었는지, Wi-Fi/모바일 데이터 여부, 표시된 오류와 대기 시간도 기록합니다. 계정 비밀번호나 서버 키는 기록하지 않습니다.

이전 실기기 검증 범위는 Android 1대와 PC의 동일 Wi-Fi 연결입니다. 가능하면 두 번째 Android 기기 및 Wi-Fi ↔ LTE/5G에서도 6번을 추가 확인해 주세요.
