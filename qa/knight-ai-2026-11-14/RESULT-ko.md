# 나이트 AI 1차 구현 및 검증 — 2026-11-14

제안서의 공통 발사 계산과 작은 후보 비교를 로컬 develop 작업본에 구현했다. 나이트의 65도 도약, 최소 속도 보정, 기존 물리·승패 규칙은 유지한다. 이 보고서는 로컬 검증 시점의 기록이며, 당시 푸시·배포·AAB 생성은 실행하지 않았다.

## 적용한 변경

- `web/src/launch.ts`: 플레이어·AI·공중 안내가 사용하는 초기 방향과 속도를 공통 계산한다.
- `web/src/ai.ts`, `knight-ai.ts`: 실제 물리 바인딩의 기물 종류와 현재 자세의 경계를 읽는다. 기존 단계별 목표를 먼저 검토하고 대체 표적 하나와 중앙 재배치를 포함해 최대 27개 후보를 비교한다. 표적별 후보는 파워 3개 × 방향 3개다. 일반 AI의 35% 입력 하한을 나이트에 강제하지 않는다.
- 공중 경로에서 먼저 만날 말·장애물과 명목상 착지 위치를 비교한다. 나이트 공격을 기대하기 어려우면 다른 기물도 선택한다. 예상 첫 접촉이 다른 적이면 그 적의 ID를 판단 결과에 기록한다.
- 기존 단계별 결정 해시·조준 오차를 후보 평가 전에 적용한다. 선택 후 화면에 보이지 않는 추가 조준 보정을 하지 않는다. 스테이지 배율은 미리보기와 실제 큐 요청에서 같은 값을 사용한다.
- `aim.ts`, `loop.ts`, `turn.ts`, `maps/control-zone.ts`: 안내선에 스테이지·제어 구역 배율을 반영한다. 제어 구역 미리보기는 읽기 전용이며 실제 발사에서 한 번 소모한다. 퀸/룩 150%와 다른 기물의 타격·회전 경로는 보존한다.
- `npm run check:knight-ai`에 공통 계산, 나이트 후보, 기존 AI 검사 진입점을 추가했다. 새 라이브러리는 없다.

## 전후 물리 측정

[측정 원본과 반복 검증](validation.json). 같은 12개 고정 배치를 단계 1·4·7·10에서 실행한 48건이다. 서로 다른 플레이어 48명이 아니다. 이 시험은 동일한 평판과 말 상태에서 AI 단계/속도만 바꾸며, 각 단계의 벽·구멍·카드 배치를 재현하지 않는다. 기울임·누움·높이 사례는 의도적으로 고정한 인공 자세다.

| 지표 | 수정 전 | 최종 수정 후 |
|---|---:|---:|
| 상대와 접촉 | 12/48 | 44/48 |
| 자기 나이트 장외 | 45/48 | 28/48 |
| 상대 장외 | 3/48 | 31/48 |
| 강제 정착 | 0 | 0 |
| 판단 중 실제 물리 월드 변경 | 0 | 0 |
| 판단 시간 p95 | 0.36ms | 0.79ms |

시간은 이 데스크톱의 Node/Rapier 실행값이며 Android 프레임 시간이나 모든 판의 최악 시간을 의미하지 않는다. 동일 시작 상태로 다시 실행한 48건에서 요청 방향·파워, 접촉, 생존, 정착 스텝과 초기 속도가 일치했다. 다른 환경까지의 전체 게임 결정성을 증명하는 검사는 아니다.

각도 ±1도에서는 접촉 44/48, 자기 장외 31/48이었다. 입력 파워 +1%p는 접촉 44/48·자기 장외 33/48, -1%p는 접촉 43/48·자기 장외 30/48이었다. 작은 차이에 따른 결과 민감성이 남아 있다. 병렬 실행한 민감도 시험의 시간은 성능 비교에 사용하지 않았다.

## 화면·발사·취소 확인

이번 제안서는 새 화면 시안이 없는 동작 제안이다. 화면 일치율을 주장하지 않고 기존 보드·HUD·선택 표시를 보존하는 범위로 비교했다.

- [수정 전 모바일 조준](baseline/knight-aim-390x844.png) / [최종 모바일 조준](after-final-03/knight-aim-390x844.png)
- 같은 제어용 2나이트 배치, 단계 4, 영어, Edge, DPR 1, 1366×768·390×844를 비교했다. 양쪽 공중 안내·선택·65도 표시가 유지된다. 모바일 기물 설명과 목표 안내의 기존 겹침은 이번 변경의 범위 밖이며 남아 있다.

- 기준 화면은 생산 코드 수정 전에 저장했다. 최종 화면 실행 중 소스 변경과 페이지 오류는 없었다. 캡처는 테스트 전용 주입으로 배치를 제어했으며, 숨긴 말의 충돌체를 제거한 완전한 물리 비교용 장면은 아니다. 초기 속도 확인과 렌더 검사에만 사용했다. 물리 결과 수치는 별도의 실제 2~3말 월드에서 측정했다.

## 남은 범위

공중 경로는 현재 자세의 AABB로 근사하며 회전·충돌·바운스 이후의 승패나 생존을 계산하지 않는다. 따라서 `nominalLandingSafe`는 충돌 전 명목 경로의 평가다. 정확한 승패/교환 점수와 정착까지 실행하는 복제 물리 탐색(KN-R03·R04의 확장)은 아직 구현하지 않았다. 고정 시험에서 개선이 확인되어 우선 이 작은 변경을 검토 대상으로 남겼으며, 특히 가까운 표적에서 최소 도약 뒤 자기 장외가 남는 문제를 해소했다고 주장하지 않는다.

실제 Android의 계산/프레임 시간, 자연 진행 중 나이트 선택 빈도·난이도, 플레이어의 체감 평가는 미검증이다. 다음 검토는 남은 자기 장외 사례에서 더 안전한 합법 샷이 있는지 비교하는 것이다. 복제 물리 탐색이나 최소 도약/마찰 변경은 그 결과를 근거로 별도 구현·검증해야 한다. 기존 난이도 수치나 물리를 함께 바꾸지 않았다.

제안서 QA 기준으로 T01·T02·T07의 초기값/생명주기, T10의 제한된 반복·민감도 시험은 수행했다. T03·T04는 인공 자세 및 근사 장애물 검사까지만 수행했고 실제 전체 지형 회귀는 미완료다. T05·T06의 복제 탐색/미정착 점수는 미구현이다. T08의 사람 난이도와 T09의 Android 성능도 남아 있다.
