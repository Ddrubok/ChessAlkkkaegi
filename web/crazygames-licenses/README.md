# Rapier notice source

The installed `@dimforge/rapier3d-compat@0.19.3/package.json` declares Apache-2.0 but does not include a LICENSE file. `RAPIER-LICENSE` was fetched on 2026-10-28 from the project's official repository:

https://raw.githubusercontent.com/dimforge/rapier.js/master/LICENSE

The CrazyGames build combines that licence with the installed Three.js, Capacitor and meshoptimizer licence files in `THIRD_PARTY_NOTICES.txt`. This notice covers runtime library licences; it does not resolve the separate game model rights hold.
