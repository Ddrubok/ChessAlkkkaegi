## 4. 코드 변경 요약

- `src/config.ts`: AI 각도 오차·파워 범위와 적 스테이지 버프 배율을 현재값 그대로 조정 가능한 상수로 분리했다.
- `src/ai.ts`: 순수 결정 함수에 선택적 오차·파워 범위 인자를 추가했다. 런타임 호출은 인자를 생략해 기존 기본값을 쓴다.
- `src/stage.ts`: 흑 중량·힘·크기 단계 증가폭에 선택적 배율 인자를 추가했다. 런타임 기본 배율은 기존과 같은 1이다.
- 합격 상수가 없으므로 설정값과 기존 W1–W5 체크 스크립트 기대값은 변경하지 않았다.

## 5. 명령·결정성

```text
node src/tools/stage-balance-sweep-v3.mjs --sweep
node src/tools/stage-balance-sweep-v3.mjs --refine
node src/tools/stage-balance-sweep-v3.mjs --verify-measurement
npx tsc --noEmit
npm run build
```

- 기본 스윕 wall time: 7.25분
- 보정 스윕 wall time: 2.71분
- 결정성 재실행: `wallTimeMs`를 제외한 24개 조합 요약 28,457자가 값·배열 순서까지 완전히 일치했다.
- 모든 seed, 카드 선택, AI·플레이어 오차는 정수 해시 기반이며 `Math.random`을 쓰지 않았다.

## 6. 한계

- 12회 표본에서는 후반 단계 도달 수가 급감하므로 1경기 결과가 승률 곡선을 크게 흔들 수 있다.
- 이번 허용 범위는 AI 오차·최대 파워·적 버프 배율뿐이다. 6개 보정에서도 1단계 승률 75%를 만들지 못했으므로, 목표를 달성하려면 더 낮은 AI 최소 파워나 AI 의사결정 정책처럼 현재 승인 범위 밖의 축을 추가 탐색해야 한다.
- 공격형 자동 플레이어는 사람의 연속 수 계획·위험 회피·카메라 판단을 모델링하지 않는다.
- 합격 상수가 없어 새 난이도의 3프로필 결과 및 R35 대비 변화는 존재하지 않는다.
