## 0. 한 줄 결론

기획서는 "10스테이지 1회 도전 → 실패하면 처음부터, 대신 포인트로 영구 성장"이라는 로그라이크 구조다.
현재 구현은 **뼈대는 같지만 수치가 거의 전부 다르고, 핵심 조작 하나가 통째로 없다.**

## 1. 기획서가 요구하는 것 (요약)

| 장 | 내용 |
|---|---|
| 02 | 런 = 10스테이지 + 목숨 1개. 플레이어 선공. 상대 말 전멸 시 즉시 승리 |
| 03 | **타격 위치가 상단/중단/하단으로 갈리고 결과가 다르다** |
| 05 | 스테이지별 상대 강화표 (중량·힘·누적 크기·폰 크기) |
| 06 | 승리 후 카드 3장 중 1장 확정 선택. 일반 2장 보장 + 3번째 일반 70 / 특수 30 |
| 07 | 같은 강화 카드는 5등급까지 성장하며 **수치는 더하지 않고 교체** |
| 08 | 특수 카드 2종: 폰 크기 상승, 누워서 시작 |
| 09 | 포인트는 임시 누적 후 패배 또는 완주 시 지급. 완주 55점 |
| 10 | 영구 테크트리: 기초 → 심화, 선행 3/3 필요, 중앙에 전체 크기 노드 |
| 11 | 테크트리 전체 322점 = 최소 6회 완주. 전체 초기화 무료·100% 반환 |
| 12 | AI는 스테이지 구간별로 판단 기준이 늘어난다 |

기획서 내부 계산은 서로 맞아떨어진다. 322점 = 기초 일반 72 + 기초 킹퀸 48 + 크기 10 + 심화 일반 120 + 심화 킹퀸 72,
완주 55점 × 6회 = 330 ≥ 322로 "최소 6회 완주"와 일치한다. 말별 최종 강화도 기초 3 + 심화 3 = 6단계 × 1% = +6%로 맞다.

## 2. 아예 없는 기능

### 2.1 ~~타격 부위 선택 — 기획서의 핵심 조작~~ → **폐기 (2026-07-28 개발자 확정)**

기획서 3장은 타격 위치를 **상단·중단·하단 세 구간**으로 나누고 상단은 쓰러뜨림, 하단은 중단의 1.5배로 규정했다.

**이 방식은 채택하지 않기로 확정했다.** 대신 **플레이어가 말 표면의 원하는 지점을 자유롭게 찍고, 그 결과는
물리에 맡긴다.** 구간을 나누지 않으므로 "상단이면 무조건 전도", "하단 1.5배" 같은 별도 규칙도 두지 않는다.

동료 브랜치(`Doobok'sbranch`, 07-28 병합)가 이 토대를 이미 넣었다 — 당구식에서 말을 고르면
`발사 / 타점선택` 버튼이 뜨고, 타점선택을 켜면 말 표면을 눌러 그 지점을 적용점으로 쓴다.
자동 계산 타점(조절판 `strikeHeightRatio`)과 직접 지정 중 **플레이어가 고르는 두 방식을 모두 유지**한다.

따라서 기획자 확인 항목이었던 "상단 전도가 무조건인지", "하단 1.5배가 힘인지 속도인지" 두 건은 **불필요해졌다.**

### 2.2 그 외

| 항목 | 기획서 | 현재 |
|---|---|---|
| 런 길이 | 10스테이지에서 끝, 완주 개념 | 상한 없음. 이기는 한 무한 |
| 포인트 지급 | 임시 누적 → 패배/완주 시 지급, 패배한 스테이지 점수 제외 | 클리어 즉시 100점 지급 |
| 카드 성장 | 5등급, 수치 **교체** (+1→3→5→7→10%) | 뽑을 때마다 **가산** |
| 카드 추첨 | 일반 2장 보장 + 3번째 일반 70 / 특수 30 | 남은 풀에서 결정적으로 3장 |
| 테크트리 구조 | 기초/심화 2구간, 선행 3/3, 중앙 전체 크기 노드 | 12노드 평면, 선행 없음 |
| 테크트리 초기화 | 무료, 100% 반환 | 없음 |
| AI 성격 | 1–3 무작위 / 4–6 장외 우선 / 7–9 연쇄 충돌 / 10 최적 | 전 구간 "가장 가까운 말" 단일 규칙 |
| AI 타격 부위 | 기본 중단, 먼 거리 하단, 전도 유리하면 상단 | 2.1에 종속 |

## 3. 있지만 값이 다른 것

### 3.1 스테이지 강화표

| 스테이지 | 기획서 중량 | 현재 중량 | 기획서 힘 | 현재 힘 | 기획서 크기 | 현재 크기 |
|---|---|---|---|---|---|---|
| 1 | 기본 | +0% | 기본 | +0% | 기본 | +0% |
| 3 | +1% | +10% | +3% | +5% | +0.3 | +3% |
| 5 | +3% | +20% | +5% | +10% | +0.3 | +3% |
| 6 | +5% | +30% | +5% | +10% | +0.6 | +6% |
| 10 | +10% | +50% | +10% | +20% | +1.0 | +9% |

현재 값 출처: `STAGE_WEIGHT_STEP=0.1` × `floor(stage/2)`, `STAGE_FORCE_STEP=0.05` × 3스테이지부터 `floor((stage-1)/2)`,
`STAGE_SIZE_STEP=0.03` × `floor(stage/3)`. 헤드리스 검증 `[통과 a]`의 단계표와 대조해 확인했다.

**폰 크기 티어(5=룩, 10=킹)만 유일하게 일치한다.**

기획서의 "누적 크기 +0.3"은 단위가 불명확하다(30%인지 절대 스케일 0.3인지). 확인 대상.

### 3.2 그 외 수치

| 항목 | 기획서 | 현재 |
|---|---|---|
| 영구 강화 상한 | 말별 힘 +6%, 중량 +6% | 말별 +10% (레벨 10 × 1%) |
| 테크트리 총비용 | **322점** | **66,000점** (12노드 × 5,500) |
| 완주 보상 | 55점 | 해당 없음 (클리어당 100점) |

**경제 규모가 약 200배 어긋나 있다.** 기획서는 완주 6회로 테크트리를 완성하는 설계이고,
현재는 스테이지 660회 클리어가 필요하다.

### 3.3 특수 카드 세부

| 항목 | 기획서 | 현재 |
|---|---|---|
| 폰 크기 상승 | 1·3·5·7번 폰 소멸 / 2·4·6·8번 킹 크기 + **다음 스테이지 부활** | a·c·e·g 소멸 / b·d·f·h 킹 크기, 부활 없음 |
| 누워서 시작 | 킹 사이드는 오른쪽, 퀸 사이드는 왼쪽으로 수평 배치 | 뒷줄은 보드 중앙 쪽(북), 폰은 동쪽으로 눕힘 |

현재 배치는 R31에서 기하를 실측해 정한 것이다(킹 길이 1.0이 랭크2 폰과 0.05 여유로 안 겹침).
기획서 배치로 바꾸면 겹침 여부를 다시 실측해야 한다.

## 4. 기획서에 없는데 이미 만든 것

- **온라인 대전(P2P)과 재대결** — 기획서에 한 줄도 없다
- **2인 대전(한 화면 번갈아)**
- 첫 화면 로딩 표시, 손맛 조절판

기획자가 PVE만 상정하고 작성한 것으로 보인다. 버릴 이유는 없으나 기획자가 알고 있어야 한다.

## 5. 기획자 확인 대기 (2026-07-28 발송)

1. **슬라이드 번호가 03 다음 05로 건너뛴다.** 04번 슬라이드가 원본에 있었는지.
2. **"누적 크기 +0.3"의 단위** — 30% 증가인지, 크기 값에 0.3을 더하는 것인지.
3. **폰 부활 대상** — "2·4·6·8번 폰: 킹 크기로 변경 · 다음 스테이지에 부활"인데 2·4·6·8은 살아 있다.
   부활 대상은 소멸한 1·3·5·7 아닌지.
4. **런 도중 메뉴 복귀 시 포인트 처리** — 기획서는 패배·완주만 규정한다.
5. **10스테이지 완주 결과 화면 문구·버튼** — 기획서에 없다.
6. **AI 구간별 조준 오차 수치** — 방향만 있고 수치가 없다.

우리가 정하고 진행한 해석 2건(뒤집기 쉽도록 `pve-design_2026-07-26.md` §3에도 기록):
전체 크기 노드는 플레이어 말 전용, 힘 강화는 일반 카드 풀 포함.

~~상단 전도가 무조건인지 / 하단 1.5배가 힘인지 속도인지~~ → **§2.1 폐기로 불필요해졌다.**

## 6. 진행 현황과 남은 순서

**완료 (2026-07-28, 전부 main 병합)**

- 영구 강화 테크트리 재편 — 3구간·선행 조건·총 322점·말별 상한 +6%·무료 전체 초기화
- 강화 카드 5등급 성장 — 수치 교체, 일반 2장 보장 + 세 번째 슬롯 70/30
- 타격 지점 자유 선택 — 동료 브랜치 병합으로 토대 확보(§2.1)

**남은 것 (전부 확인 대기)**

1. 런 길이 10스테이지 + 포인트 후불 정산 + 완주 55점 — 확인 4·5번
2. 스테이지 강화표 — 확인 2번
3. AI 구간별 판단 기준 — 확인 6번
4. 조절판 스테이지 번호 이동(개발용) — 개발자 결정 대기.
   지금은 6스테이지 체감을 보려면 5판을 이겨야 해서 기획서 12장의 "증가량 체감" 테스트가 사실상 불가능하다.

남은 넷은 서로 독립이라 답이 오는 순서대로 착수하면 된다.
