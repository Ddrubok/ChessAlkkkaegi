## 0. 목표와 비목표

**목표**: 내 말을 골라 → 방향·세기를 조준해 → 튕긴다 → 물리로 굴러가 다른 말을 맞히고 넘어뜨린다 → 멈추면 다음 차례.
마우스·터치 모두 동작. **이 슬라이스가 끝나면 실제로 플레이할 수 있고, Unity 버전과의 조작감 비교가 시작된다.**

**비목표**: 승패 판정·완성형 턴 규칙(슬라이스 3), AI, 온라인, 강화, 사운드.
**v1에서 뺀 것(게이트1 권고)**: 예측선, 카메라 흔들림 — 둘 다 핵심 손맛 검증을 늦추므로 감각 확정 후 옵션으로 추가한다.

## 1. 조작 — 당겼다 놓기

- **선택**: 내 차례 진영의 말을 클릭(탭). 화면에 선택 표시.
- **조준**: 선택된 말에서 드래그. **드래그 반대 방향으로 발사**(고무줄 직관). 거리 = 세기, `MAX_DRAG_PIXELS`에서 100%.
- **발사**: 놓는 순간 임펄스.
- **취소**: `Esc`, 또는 **놓은 좌표가 캔버스 경계 밖**일 때.
- 표시: **방향 화살표**(길이 = 세기) + **세기 %**(색: 흰→붉음). 예측선 없음.

### 1-1. 포인터 상태 기계 (게이트1 지적 3 — 높음)

같은 캔버스를 OrbitControls와 게임 입력이 공유하므로 명시적으로 정의한다.

- 상태: `idle` → `aiming` → (`launch` | `cancel`) → `idle`.
- **활성 포인터는 항상 1개**(`activePointerId`). 조준 중 들어온 두 번째 포인터는 **무시**한다.
- **캡처 단계(capture phase)에서 말 선택 여부를 먼저 판정**하고, 내 말이면 그 자리에서 OrbitControls를 잠근다.
  선택 후에 잠그면 같은 이벤트로 이미 카메라가 돌기 시작한다.
- `setPointerCapture`를 쓰면 캔버스 밖에서 놓아도 `pointerup`이 캔버스로 오므로,
  **취소 판정은 release 좌표가 캔버스 사각형 안인지 직접 검사**해서 한다.
- `pointercancel`, `lostpointercapture`, `blur`, `visibilitychange`에서도 조준을 정리한다.
- **정착 중·턴 카메라 회전 중·제거 대기 중인 말은 선택 불가.**

### 1-2. 선택 규칙 (지적 11)

- **raycast의 가장 가까운 첫 교차만** 판정한다. 그것이 상대 말이면 **선택 실패로 끝낸다**
  (뒤에 있는 아군 말을 뚫고 선택하지 않는다).
- **선택 표시는 말의 자식이 아니라 월드 수평 표시**로 두고, 말의 **현재 월드 AABB 바닥**에 놓는다.
  자식으로 붙이면 누운 말에서 표시도 같이 누워 안 보인다.

## 2. 카메라

- **상하각 고정**(`CAMERA_PITCH_DEG`), 수평 회전만, 팬 금지, 줌 허용.
  상하각이 바뀌면 "화면에서 아래로 드래그" ↔ "판 위에서 내 쪽으로"의 대응이 깨진다.
- 턴이 바뀌면 반대편으로 부드럽게 회전(항상 내 진영이 화면 아래). **회전 중에는 선택·조준 잠금.**
- **세로 화면 대응 (지적 1 — 높음)**: 현재 구성(세로 FOV 42°, 거리 5.50)은 9:16 세로에서 보이는 폭이 약 2.38로
  보드 폭 4.556을 못 담고, 최대 거리 9.11에서도 약 3.94에 그친다.
  → **리사이즈 때 종횡비로 "보드 전체가 들어오는 최소 거리"를 계산해 카메라 거리와 `maxDistance`를 함께 조정**한다.
  가로·세로 어느 쪽이든 보드 폭·깊이가 모두 화면에 들어와야 한다.

### 2-1. 드래그 → 월드 방향 (지적 2)

- `pointerdown` 시점에 카메라 right/forward를 **판 평면(xz)에 투영하고 정규화해 조준이 끝날 때까지 고정**한다.
  매 프레임 다시 구하면 턴 회전 중 같은 드래그가 다른 방향이 된다. 정규화하지 않으면 피치에 따라 세로 감도가 달라진다.
- 백·흑 각 시점에서 화면 Y 증가 방향과 발사 방향의 부호를 각각 확인한다.

## 3. 물리 — 임펄스

- **적용점 (지적 4 — 높음)**: Rapier `applyImpulseAtPoint(impulse, point, wakeUp)`의 `point`는 **월드 좌표**다
  (`rigid_body.d.ts:492-498`).
  - x/z = `body.worldCom()`의 x/z. (피벗 x/z를 쓰면 Knight처럼 COM이 치우친 말에 의도치 않은 yaw가 생긴다)
  - y = **현재 월드 AABB의 `minY` + `FLICK_HEIGHT_RATIO` × 현재 AABB 높이.**
    현재 AABB 기준이므로 **누운 말에도 그대로 정의된다.**
  - `FLICK_HEIGHT_RATIO = 0.25`.
- **세기**: `impulse = mass × normalizedPower × MAX_LAUNCH_SPEED`.
  - 질량을 곱하므로 즉시 속도 변화 `Δv = normalizedPower × MAX_LAUNCH_SPEED`가 되어 **모든 말이 같은 속도로 출발**한다.
    곱하지 않으면 Pawn(0.027)과 King(0.103) 사이에 시작 속도가 약 3.8배 벌어져 조준이 불가능해진다.
    무게 차이는 **충돌 시 운동량**으로 드러난다.
  - **`SCALE_IMPULSE_BY_MASS` 선택지는 두지 않는다**(지적 6). 이름도 `MAX_LAUNCH_SPEED`로 두어 단위를 분명히 한다.
  - **`MAX_LAUNCH_SPEED = 11`** — 게이트1 헤드리스 실측: 비율 0.25, 빈 평면, 정착된 말, 축 방향 플릭에서
    6종 이동 거리 6.520~7.764칸(속도 10이면 5.724칸까지, 12면 일부 8칸 초과).
- **넘어짐은 정상이다 (지적 5)**: 실측상 어떤 적용점 비율로도 강한 샷에서 6종을 모두 직립 유지시킬 수 없었다
  (비율 0.25·속도 10에서 최대 기울기 109~176°). 우리 규칙은 **누운 말도 계속 플레이**하므로 이는 결함이 아니다.
  감각 목표를 "약하게 치면 미끄러지고, 세게 치면 굴러간다"로 명시한다.

## 4. 정지 판정과 턴 (지적 8 — 높음)

- **판정**: 각 바디가 `sleeping || (선속도 < REST_LINEAR_EPS && 각속도 < REST_ANGULAR_EPS)`.
  하나라도 초과하면 hold 누적을 **0으로 초기화**한다. 선속도만 보면 제자리에서 도는 말이 정지로 잡힌다.
- **순서**: 매 fixed step 후 **① 낙하 말 제거 → ② 정지 판정**. 순서를 바꾸면 떨어지는 말이 영원히 정지를 막는다.
- `REST_HOLD_SECONDS`(0.3 시뮬레이션 초) 동안 유지되면 정지로 본다.
- **타임아웃**: `MAX_SETTLE_SECONDS`(8 시뮬레이션 초 ≈ 실제 2.53초)를 넘으면
  **접촉 중이면서 저속인 말만** 속도를 0으로 만들고 sleep시킨다.
  **여전히 고속이거나 공중에 있는 말이 하나라도 있으면 턴을 넘기지 않는다.**
  무조건 `sleep()`하면 말이 공중에서 멈춘다.
- **턴**: 백 선공, 한 번 튕기면 상대 차례. 자기 진영 말만 선택 가능. 보너스 턴 없음(슬라이스 3에서 재검토).

## 5. 낙하 말 제거 (지적 9)

- 기준: 원점 y < `FALL_OUT_Y`. 승패 판정은 하지 않는다(슬라이스 3).
- `world.removeRigidBody(body)`는 collider·joint를 함께 제거하고 접촉 중이던 바디를 깨운다(`world.d.ts:267-274`).
- **각 fixed step이 끝난 뒤 제거 대상을 모아 일괄 처리**한다. 순회 중 즉시 제거 금지.
- 함께 정리할 것: 강체, Three.js 메시, 물리-렌더 바인딩, 선택 가능 목록, 현재 선택·조준 상태.
  **공유 geometry/material은 dispose하지 않는다.**
- 상대 턴 정착 중에 떨어진 말도 다음 턴 판정 전에 제거한다.

## 6. 타격감 (최소)

- **발사 순간**: 화살표가 튕기듯 사라지고, 친 말에 짧은 스케일 펄스(1.0→1.06→1.0, 0.12초).
  **렌더 메시에만 적용하고 콜라이더 크기는 건드리지 않는다.**
- 카메라 흔들림·사운드·낙하 연출 없음(v1 제외).

## 7. 파일 구조

기존 7모듈 + `input.ts`(포인터 상태 기계·선택), `aim.ts`(방향·세기·표시), `turn.ts`(턴·정지 판정·낙하 제거).
`config.ts` 추가 상수: `MAX_DRAG_PIXELS`, `MAX_LAUNCH_SPEED`, `FLICK_HEIGHT_RATIO`,
`REST_LINEAR_EPS`, `REST_ANGULAR_EPS`, `REST_HOLD_SECONDS`, `MAX_SETTLE_SECONDS`, `FALL_OUT_Y`, `CAMERA_PITCH_DEG`.

## 8. 수락 기준 (게이트2 — 정량, 지적 12 반영)

**조작**
- [ ] 내 말만 선택되고, 상대 말이 앞을 가리면 선택 실패한다(뚫고 선택 안 됨)
- [ ] 드래그 중 화살표·세기 %가 드래그 **반대** 방향으로 표시된다 (백·흑 양쪽 시점에서 각각 확인)
- [ ] `Esc` 또는 캔버스 밖 release 시 발사되지 않는다
- [ ] 조준 중 두 번째 손가락이 들어와도 조준이 깨지지 않는다
- [ ] `pointercancel`·창 포커스 상실 후 조준 상태가 남지 않는다
- [ ] 조준 중 카메라가 돌지 않는다

**물리**
- [ ] 임펄스 직후 **첫 physics step 전에** `|Δv − target| / target ≤ 1%` (6종 전부)
- [ ] 적용점이 월드 좌표이며, **직립 말과 누운 말 각각의 실제 적용점 좌표를 로그로 기록**
- [ ] 빈 평면 기준 시험(정착된 말, 비율 0.25, 축 방향, 최대 세기)에서 6종 이동 거리 **6~8칸**
- [ ] 누운 말도 선택·조준·발사된다

**정지·턴**
- [ ] 제자리에서 회전만 하는 말이 있으면 정지로 판정되지 않는다(각속도 포함 확인)
- [ ] 낙하 말이 제거되고, 유령 메시·잘못된 정지 판정이 없다
- [ ] 강제 정착이 발동한 순간 **살아 있는 모든 말이 정지 상태이고 공중 낙하 중인 말이 0개**
- [ ] 모든 말이 멈추면 차례가 넘어가고 카메라가 반대편으로 회전한다

**프레임률 독립성**
- [ ] 동일 초기 스냅샷·동일 드래그 벡터로, 임펄스를 **다음 fixed-step 경계에서** 적용
- [ ] 30/60/120/165 fps에서 **동일한 physics step 수 경과 후** 단일 말의 위치·속도·회전이 허용 오차 내 일치
- [ ] 워밍업 뒤 전경 플레이 중과 명시적 일시정지 뒤에 버려진 시뮬레이션 시간과 accumulator overflow 횟수 **0**

**모바일**
- [ ] 세로 화면에서 보드 전체가 화면에 들어온다
- [ ] 한 손가락 조준·발사가 동작한다

**기타**
- [ ] 콘솔 에러 0, `npm run build` 성공, dist에 tools 없음
- [ ] `unity/`·`resource/` 무변경

## 9. 개발자 확인 대기 (진행은 막지 않음)

1. **예측선** — v1에서 제외했다(게이트1 권고: 중심 ray는 부피·스침 충돌을 잘못 예측하고, 정확히 하려면 `castShape`가 필요해
   핵심 감각 검증이 늦어진다). 손맛 확정 후 옵션으로 추가 가능.
2. **한 턴 한 번** — 유지. 상대 말을 떨어뜨리면 보너스 턴을 주는 규칙은 슬라이스 3의 승패 규칙과 함께 결정.
3. **최대 세기** — `MAX_LAUNCH_SPEED = 11`로 시작(실측 6.5~7.8칸). 실제로 쳐보고 조정.
