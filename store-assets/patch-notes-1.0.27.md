# 체스알까기 1.0.27

## 한국어

- 작은 게임판에서 클래식 모드의 마우스 ‘보통’·‘정밀’ 당김 설정으로 약한 샷의 세기를 더 세밀하게 조절할 수 있습니다. 최대 세기에 도달하는 거리는 그대로입니다.
- 약한 샷 연습은 화면에 표시된 정수 퍼센트로 30~50% 성공 여부를 판정합니다. 연습 결과와 표시된 세기가 서로 다르게 보이던 경우를 바로잡았습니다.
- 게임 파일 다운로드나 그래픽 초기화에 실패하면 원인에 맞는 안내와 ‘다시 시도’ 버튼이 표시됩니다. 연습, 온라인 대전, 벽과 말 선택 안내도 게임의 지원 언어로 표시됩니다.
- 혼자 하기에서 패배와 직접 종료한 도전을 결과 화면에서 구분하고, 경기가 끝난 뒤 남아 있던 스테이지 도움말을 지웠습니다.
- **CrazyGames** 첫 방문의 개인정보 안내를 지원 언어로 제공하고, 첫 샷을 놓은 뒤 안내가 닫히도록 조정했습니다. 게스트의 빠른 시작 안내와 상단 조작 버튼이 겹치지 않도록 배치했습니다.

## English

- On small boards, the Standard and Precise mouse pull settings give finer control over soft shots in Classic mode. The pull distance to full power stays the same.
- Soft-shot practice now judges the displayed whole-number power percentage. A shot shown as 30–50% produces the matching practice result.
- If game files fail to load or graphics cannot start, the game shows a specific explanation and a Try again button. Practice, online, wall, and piece guidance now appears in the game's supported languages.
- Solo results distinguish a loss from a run you ended yourself, and stage tips clear when a match ends.
- On **CrazyGames**, the first-visit privacy notice uses the selected language and closes after the first shot is released. The guest quick-start guide and top controls no longer overlap.
