- 명시적 정책: 패배/무승부는 단계·런 카드·임시 포인트를 유지하고 지급·런 삭제 없이 같은 단계 무제한 재도전한다. 재도전 보드는 양측 말·장애물·구멍·벽·특수 능력 사용권을 단계 시작 상태로 다시 만든다. 메뉴 이동은 지급 없는 일시 중단/저장 경계다. 별도의 **확인된 런 종료**만 이전 클리어 보상을 한 번 정산하고 런을 지운다. 새 런 재시작은 이 종료 거래가 확정된 뒤에만 허용한다.
- 승리 1~9단계는 카드 선택 전부터 확정 제안을 저장하고, 선택은 한 번 확정된 뒤 다음 보드를 준비한다. 10단계 승리는 한 번 완주·정산한다. 저장/복원 경계는 단계 시작·카드 제안·선택 확정·종료 거래이며 샷 도중 물리 상태 복원은 요구하지 않는다.
- 소유자(게스트/계정)+규칙셋 범위의 런·보상 ID를 사용한다. 로컬 체크포인트를 계정 지급 영수증으로 신뢰하지 않는다. v2 저장은 소유자·규칙·상태가 모호하지 않을 때만 이행하고, 계정 포인트를 체크포인트 값으로 덮지 않는다. 저장 불가 시 해당 세션 재도전만 허용하고 영속되지 않음을 명시한다. 다음 보드 구성/저장 실패는 이미 확정된 목표로 재시도하며 카드·보상을 중복하지 않는다.
- 제외: 온라인·주간·퍼즐·튜토리얼·2인 대전 및 웹·Android·CrazyGames의 신규 적용. 공통 코드 영향의 **회귀 검사만** 수행한다. 킹 목표·역할/위력/카드 변경은 별도 실험 게이트를 통과하기 전 기본 게임에 적용하지 않는다.
- v1.0 초기 계획 당시 모든 아래 자식 사례의 구현 상태 `not-started`, 검증 상태 `not-run`, 실제 결과·증거 `none`. 제안서의 기존 기능·정적 조사·과거 나이트 시험은 준비 자료일 뿐 신규 사례의 통과 증거가 아니다. P1=진행/보상/계정 무결성, P2=일반 흐름·회복·실험 핵심, P3=표현·탐색. `핵심`은 1차 출시, `실험`은 후속 개발 게이트, `회귀`는 제외 경로 무변경 검사다.
