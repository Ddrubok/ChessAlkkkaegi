# Google 로그인 및 QA 수정 — 2026-09-19

## 사용자 변경 사항

- Google로 계속하기: 첫 인증은 회원가입, 이후에는 로그인. 운영 Google 제공자가 활성화된 경우에만 버튼이 표시됩니다.
- 회원 친선전: 친선전에서 친구 목록으로 이동하여 친구 추가·초대. 게스트는 12자리 코드로 입장하며 응답 코드를 복사할 필요가 없습니다.
- 친구 초대 수신 콜백 누락, 늦은 참가의 연결 신호 유실, 중복 신호, 취소 후 늦은 수락을 처리했습니다. 친선전은 MMR 정산 및 랭킹 승리 퀘스트에서 제외합니다.
- 클래식 조준 취소: 취소 영역으로 드래그, PC Esc·우클릭, 모바일 추가 터치. 취소 시 발사/턴 소비가 없습니다.
- 설정 320px 넘침, 탭 전환 중 꾸미기 임시 선택 소실, 도감 기본 칭호·프레임 표시, 모달 포커스, 주간 도전 갱신 시 스크롤 초기화를 수정했습니다.

## 운영 설정

[Google 로그인 설정](../supabase/GOOGLE_AUTH_SETUP.md)을 완료해야 Google 로그인을 사용할 수 있습니다. 추가 SQL은 없습니다.
Android 복귀 링크와 공식 Capacitor App/Browser 플러그인을 추가했습니다. 기존 설치 앱에는 새 앱 빌드 배포가 필요합니다.

## 검증 범위

- 웹 프로덕션 빌드 및 기존 회귀/꾸미기/계정 진행도/로비/광고 검사.
- `npm run check:auth-interaction`: Google 콜백 경로·PKCE 코드 교환·만료·중복·재시도, 친선 코드, 발사 취소 검증. CI에 추가했습니다.
- Edge 실제 브라우저에서 320px Google 버튼/9개 언어/실패 안내 및 재시도, 설정 320px, 주간 도전 30초 갱신 후 스크롤 유지.
- 실제 로컬 WebRTC와 가짜 Realtime 중계로 두 참여자의 늦은 참가·신호 유실/중복·데이터 전달 검증.
- 실제 브라우저 포인터/터치 에뮬레이션으로 Esc·우클릭·취소 영역 드래그·touchCancel 시 미발사 검증.
- Android Debug 빌드로 새 네이티브 플러그인과 매니페스트 컴파일 확인.

Google 실제 계정 인증과 Android 실기기 복귀는 운영 제공자 설정 후 확인해야 합니다. 외부 네트워크 간 연결/TURN은 실기기 후속 확인 대상입니다.
